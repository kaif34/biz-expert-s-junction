# Biz Expert's Junction UI

Biz Expert's Junction is a modern, responsive web application built for a leading recruitment consultancy firm in India. It provides tailored manpower solutions including permanent hiring, bulk recruitment, and contractual staffing.

## Features

- **Modern UI/UX**: Built with React and Tailwind CSS, featuring a beautiful and responsive design.
- **Animations**: Smooth page transitions and scroll animations using Motion.
- **Accessible Components**: Utilizes Radix UI for highly accessible, robust UI components.
- **Fast Performance**: Bundled with Vite for instant server start and lightning-fast HMR.
- **Form Handling**: Robust form validation using React Hook Form and Zod.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **State Management & Fetching**: [TanStack Query](https://tanstack.com/query)
- **UI Components**: [Radix UI](https://www.radix-ui.com/)
- **Animations**: [Motion](https://motion.dev/)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js)

### Installation

1. Clone the repository and navigate to the project directory:
   ```sh
   cd biz-expert-s-junction-ui
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

## Building for Production

To create a production-ready build, run:
```sh
npm run build
```

This will generate an optimized build in the `dist` folder. You can preview the built application locally by running:
```sh
npm run preview
```

## Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Creates a production build.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs ESLint to analyze the code for issues.
- `npm run format`: Runs Prettier to format the codebase.
